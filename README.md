## 🛠️ THE FORENSIC CORE: 4 CUSTOM STATISTICAL ENGINES

PriceGhost does not rely on simple LLM wrappers. The dynamic discrimination report is backed by four rigorous mathematical algorithms running natively in Node.js:

1.  **Gini Coefficient of Spatial Inequality ($G$):**
    Quantifies the exact price disparity across all search channels. Maps spreads from $0.0$ (perfect uniform fair market) to $1.0$ (extreme location exploitation).
    $$G = \frac{\sum_{i=1}^{n}\sum_{j=1}^{n}|x_i - x_j|}{2n^2\mu}$$
2.  **Coefficient of Variation (CV %):**
    Measures price volatility as a percentage deviation from the global average.
3.  **Mann-Whitney U Significance Test:**
    A non-parametric distribution check clustering locations into low-GDP and high-GDP layers to verify that price discrepancies are not due to random fluctuations ($p < 0.05$).
4.  **GDP Pearson Wealth Correlation ($r$):**
    Isolates dynamic purchasing-power extraction by calculating the linear correlation between a visitor's host country GDP per capita and the price they are charged.
    $$r = \frac{\sum (x - \bar{x})(y - \bar{y})}{\sqrt{\sum (x - \bar{x})^2 \sum (y - \bar{y})^2}}$$

## ⚡ QUICK STARTUP

### 1. Configure Credentials
Create `priceghost/.env.local` and enter your hackathon credentials:
```env
BRIGHT_DATA_API_KEY=your_bright_data_api_key_here
BRIGHT_DATA_ZONE=your_bright_data_proxy_zone_here
AIML_API_KEY=your_aiml_api_key_here
FEATHERLESS_API_KEY=your_featherless_api_key_here
COGNEE_API_KEY=your_cognee_api_key_here
TRIGGERWARE_API_KEY=your_triggerware_api_key_here
```

### 2. Initialize and Seed SQLite Ledger
Execute the database seeder to establish schema and load historical pricing matrix profiles:
```bash
cd priceghost
node scripts/seed.js
```

### 3. Run Development Server
Boot Next.js with Turbopack acceleration:
```bash
npm run dev
```
Open `http://localhost:3000` to begin.
